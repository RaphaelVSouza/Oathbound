# Especificação

Consolide as decisões existentes em objetivo, contexto, comportamento esperado,
limites, riscos e critérios de aceite observáveis. Aponte fontes e mantenha
questões não decididas como `PENDENTE`, com responsável quando conhecido.

Escreva a spec no local definido pelo tracker. Não invente uma entrevista se a
conversa já contém as respostas. Peça decisão apenas quando ela impedir uma
spec correta. A spec precisa ser aprovada segundo o contrato do projeto antes
da decomposição em tickets, caso esse contrato exija aprovação.
