3 Docs e site tokens semânticos · claro e escuro

Para leitura longa, o fundo clareia (papel em vez de pergaminho) e o escuro fica em ferro quase preto. O lacre vira a cor de link e de erro, o latão marca a presença da marca, e o verde de "juramento cumprido" é reservado para resultados de auditoria. Os tokens ficam em .th-light e .th-dark no topo do arquivo.

Oaths

An oath binds one agent to a role, an authorized file scope and an acceptance criterion. Git checks the working tree before and after the run. See Git audit.

$ oathbound run smith --oath fix-login
✓ scope src/auth/** · 3 files
✓ accept npm test · 42 passed
✓ assayer oath kept
smith assayer archivist
OATH BROKEN smith touched package.json, outside the authorized scope. The run was rejected.

2 A guilda emblemas de ofício · 1 cor por agente

Como os emblemas de classe de RPG de mesa, cada ofício tem um glifo próprio e uma cor. Todos ficam na mesma plaqueta, para a guilda ser lida como uma família. O glifo é vazado em pergaminho, e as cores ficam em --ag-* no topo do arquivo.

OATHKEEPERdelega · não edita nem commita
SURVEYORlê o código · responde arquivo:linha
SCHOLARpesquisa em fontes externas
SCRIBEspec, tickets e decisões
SMITHimplementação
ASSAYERrevisão a frio do diff
WARDENsegurança · AppSec
BREAKERteste de mutação
HERALDREADME, CHANGELOG e PR
ARCHIVISTprepara hunks e commits

C Nó de juramento Jost Medium · 2 cores

Um tronco com um commit em cada ponta e uma volta que sai, contorna e retorna, trançada por cima e por baixo. Lido como corda é um nó; lido como grafo é um branch que diverge, passa pela verificação e volta a se fundir. A volta ainda desenha um b discreto, de bound.
