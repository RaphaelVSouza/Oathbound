# Claude Code

A skill instalada fica em `.claude/skills/agent-governance/`. Para que Claude
leia as regras compartilhadas do projeto, mantenha um `CLAUDE.md` curto que
importe `AGENTS.md` (`@AGENTS.md`) quando essa for a convenção do projeto.

Coloque políticas duráveis e específicas do domínio em `AGENTS.md` ou nas
referências que ele aponta. Memória conversacional pode guardar histórico,
mas não deve ser a única fonte de uma regra operacional.
