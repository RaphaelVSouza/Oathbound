# Set up the Antigravity shortcut

Proceed only when the user explicitly invokes this skill. Apply [the shell setup instructions](references/shell-setup.md) with shortcut `agy:oathkeeper` and command `agy --agent oathkeeper`.

Check that `agy agents` lists `oathkeeper` before writing. If the agent is missing, report the prerequisite.
